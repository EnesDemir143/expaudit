# Review Taxonomy

Statuses are `confirmed`, `high-confidence`, `review-required`, `not-executable`, `not-applicable`, and `passed`. Verdicts are `not-reliable-yet`, `reliable-with-caveats`, `reliable-enough`, and `blocked-insufficient-evidence`.

Review split leakage, test reuse, duplicate/group overlap, loss activation misuse, evaluation mode and no-grad behavior, shape/broadcasting, trainable parameters, LLM loss masks, tokenizer revisions, and train-serving normalization/postprocess skew.
