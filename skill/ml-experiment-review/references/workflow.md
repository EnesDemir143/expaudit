# Workflow

Contract fields are identity, hypothesis, baseline, intended change, data, evaluation, acceptance, implementation, and reproducibility. Each has source, state, confidence, and evidence. Never replace a missing field with a plausible assumption.

Pre-run reviews validate design and do not claim run results. Post-run reviews validate declared versus observed behavior. Comparisons require controlled-variable parity before attribution. Repository health reviews identify code, data, and reproducibility risks without inventing experiment intent.
